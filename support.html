Tic Tac Toe Support

Last updated: August 9, 2026

Welcome to Tic Tac Toe Support.

Tic Tac Toe lets you play a classic two-player game locally on the same device or online with another player using a private room code.

How to Play

Play Local

  1. Open Tic Tac Toe.
  2. Select Play Local.
  3. Player X starts the game.
  4. Players take turns selecting an empty square.
  5. The first player to get three symbols in a row wins.
  6. Select Play Again to start a new game.

Play Online

  1. Open Tic Tac Toe.
  2. Select Play Online.
  3. Select Create Game.
  4. Share the six-digit room code with your friend.
  5. Your friend selects Play Online.
  6. Your friend enters the room code.
  7. Once the second player joins, the game starts.
  8. Players take turns making moves.
  9. Select Play Again when the game ends.

Online Game Issues

My friend cannot join my game

Please check that:

  • The room code is correct.
  • The room code contains all six digits.
  • The game has not already been joined by another player.
  • Both devices have an active internet connection.
  • Both players are using the latest version of the app.

The game is not updating

Online games require an active internet connection.

  1. Check your Wi-Fi or cellular connection.
  2. Close and reopen the app.
  3. Create a new game room if the problem continues.
  4. Make sure both players are using the latest version.

I cannot create a game

Make sure your device has an active internet connection. If the problem continues, please contact support.

I cannot join a game

Make sure:

  • The room code is correct.
  • The room has not already reached two players.
  • You are not trying to join your own room.
  • Your device has an active internet connection.

Privacy

If you experience a problem that is not covered above, please contact us with:

  • A description of the problem
  • The game mode you were using
  • Your device model
  • Your iOS version
  • The version of Tic Tac Toe you are using
